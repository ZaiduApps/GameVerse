# API Contract

The Web runtime keeps its existing API and proxy behavior. The compile-time contract is generated by `AC-interface` from its Swagger document.

```powershell
$env:AC_INTERFACE_ROOT = 'D:\\APKSCC\\AC-interface'
pnpm contract:check
```

Run `pnpm contract:sync` after the backend contract changes. The generated file is compile-time only and does not change runtime requests or require the Web app to use a generated client.
